## Introduction
This demo shows the working MQTT Telemetry Simulator, FastAPI API, anomaly scenarios, and Streamlit dashboard.

## Demo Flow

1. Start the FastAPI server.
2. Open Swagger API documentation.
3. Check the `/health` endpoint.
4. Check the `/scenarios` endpoint.
5. Generate normal battery telemetry.
6. Generate a replay attack scenario.
7. Verify the `REPLAY_DETECTED` anomaly.
8. Open the Streamlit dashboard.
9. Generate normal telemetry events.
10. Generate replay attack events.
11. Download telemetry data as CSV.
12. Show the automated test result.
